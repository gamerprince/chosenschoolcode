Chosen Generation Portal User Guide

School operations guide for administrators, teachers, and students

1. Admin Guide

Role: Admin registers teachers and manages school-wide access.

  1. Open the website homepage.
  2. Click Portal.
  3. Click Admin Portal.
  4. Enter the admin email and password.
  5. Click Sign In.

Admin responsibilities

  • Register new teachers.
  • Assign teacher access and permissions.
  • Manage student result records.
  • Approve or publish results.
  • Monitor class performance and broadsheet reports.
Important: The admin is the first person who creates and authorizes teacher accounts. Without the admin, teachers cannot access the system properly.

How admin manages teachers

  1. Open the admin dashboard.
  2. Go to the teacher management section.
  3. Enter the teacher name and email.
  4. Create the teacher account.
  5. Share the temporary login details with the teacher.

How admin checks results

  1. Open Manage Results.
  2. Select class.
  3. Select term or annual result.
  4. Type the session year.
  5. Click Load Students.
  6. Approve fee status and publish results if needed.

2. Teacher Guide

Role: Teachers create tests, register subjects, manage class results, and help students access their exams.

  1. Open the homepage.
  2. Click Portal.
  3. Click Teacher Portal.
  4. Enter the teacher email and password.
  5. Click Sign In.

Teacher dashboard

After login, the teacher will see the dashboard with the main actions:

  • Create New Test
  • Manage My Tests
  • Register My Subjects
  • Enter Result
  • Process Result

How to register subjects

  1. Click Register My Subjects.
  2. Select the class.
  3. Tick the subjects taught in that class.
  4. Click Save Subject Selection.
Tip: This step is important because subject assignment connects the teacher to a class. The system uses it to show the right subjects when creating tests and results.

How to create a test

  1. Click Create New Test.
  2. Enter the test title.
  3. Select the class.
  4. Select the subject.
  5. Paste questions in the required format.
  6. Use the correct answer format, for example:

Example:

1. What is the capital of France?
A. London
B. Paris
C. Berlin
D. Madrid
Ans: B

  1. Click Parse & Preview to check the questions.
  2. Click Save as Published when ready.
Important: Leave a blank line between each question. If the format is not correct, the test may not parse properly.

How to manage tests

  1. Click Manage My Tests.
  2. View all created tests.
  3. Edit or remove any test if needed.

How to enter student results

  1. Click Enter Result.
  2. Select the student class.
  3. Select the term/session.
  4. Enter the student score and result details.
  5. Save the result.

How to process results

  1. Click Process Result.
  2. Choose the class.
  3. Review the result records.
  4. Finalize and publish the result.
Teacher priority: Teachers are the main users in this system because they create student accounts, prepare tests, and manage classroom result records.

3. Student Guide

Role: Students log in to see published exams and complete assignments.

  1. Open the homepage.
  2. Click Portal.
  3. Click Student Exam.

Student login

  1. Enter email.
  2. Enter password.
  3. Click Sign In.

How a student account is created

  1. Click Register.
  2. Enter full name, email, password, and class.
  3. Click Create Account.
Teacher role: Teachers usually create or help register student accounts so the student can access the exam portal correctly.

After login

  1. The student sees the list of available tests.
  2. Only published tests appear.
  3. Click Take Exam on the chosen test.

During the exam

  1. Read each question.
  2. Select the correct option.
  3. Move to the next question.
  4. Submit the exam when finished.

What if the student cannot see the exam?

  • The teacher may not have published the exam yet.
  • The student may be in the wrong class.
  • The account may not have been created properly.
Summary: The teacher is the key user because they create class subjects, open exams, manage student accounts, and process results. The admin supports access and account management, while students use the portal mainly to take tests and check results.
